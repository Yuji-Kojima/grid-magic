# grid-magic
geminiに作ってもらったゲーム
https://yuji-kojima.github.io/grid-magic/

 ## ゲームのルール:
 ・スワイプで好きなマスに移動します。  
 ・赤いマスはダメージマスで、移動後にそのマスにいると即死です。外側にいる敵の数だけダメージマスは増えていきます。  
 ・敵を倒すと稀にシールドがドロップして、装備するとダメージを受けるときに代わりにシールドが全て破壊されます。  
 ・シールドを持った状態でシールドを重ねて取得すると、その分だけ次のターンからスコア倍率が上がります。  
 
 **移動時に、軌道によってさまざまな攻撃ができます。**  
 ・直線:  
  長さによって威力が異なるビームを、移動方向にまっすぐ放ちます。  
 ・L字:   
  着地点の斜め4マスに爆発を起こします。角から角に移動した場合、追加でビームを移動方向にまっすぐ放ちます。  
 ・正方形:  
  空いたマスのサイズのビームを、自機に重なるように差し込んだ矢印の方向にまっすぐ放ちます。  
 ・その他:  
  移動のみ。
